## 🇬🇧 English

### Why FreskoRusse

FreskoRusse is a web app for French speakers who are about to study or live in Russia. Instead of asking learners to repeat endings until they stick, it explains the logic behind each case (who acts, what is affected, who receives, where things happen) so that the right ending can be chosen naturally. It is free, installable, and works offline.

### Features

| Module | What you get |
|---|---|
| **Russian cases** | The 6 cases with endings, examples and interactive lessons, plus a general logic overview and a guide to choosing between hard and soft endings. |
| **Conjugation** | 62 essential verbs in the present, past and future, with both aspects. |
| **Word bank** | 285 Russian words close to French, as flip flashcards. |
| **Useful phrases** | Visa, university, housing and daily life, for your arrival. |
| **Library** | A random text of a surprise level, from beginner to advanced. |
| **Dictation** | Listen to or read a Russian sentence and write what you hear. |
| **Translation** | French ↔ Russian sentences at your own pace, self-assessed. |

Also included: an XP progress counter, a dark mode, a search bar and installation as an app.

### Try it

The live version is available at **[freskorussedist.vercel.app](https://freskorussedist.vercel.app/)**. On a phone or in a compatible browser, use the « Install the app » button to add it to your home screen and use it offline.

### Run it locally

```bash
git clone https://github.com/femom/freskorusse.git
cd freskorusse
npm install
npm run dev
```

To produce the production build:

```bash
npm run build
```

## 🇫🇷 Français

### Pourquoi FreskoRusse

FreskoRusse est une application web pour les francophones qui s'apprêtent à étudier ou à vivre en Russie. Plutôt que de faire répéter des terminaisons jusqu'à ce qu'elles restent, elle explique la logique de chaque cas (qui agit, ce qui est touché, qui reçoit, où se passent les choses) pour que la bonne terminaison vienne naturellement. Elle est gratuite, installable et fonctionne hors-ligne.

### Fonctionnalités

| Module | Contenu |
|---|---|
| **Les cas russes** | Les 6 cas avec terminaisons, exemples et leçons interactives, une vue d'ensemble de la logique générale et un guide pour choisir entre terminaisons dures et molles. |
| **Conjugaison** | 62 verbes essentiels au présent, au passé et au futur, avec les deux aspects. |
| **Banque de mots** | 285 mots russes proches du français, en flashcards à retourner. |
| **Phrases utiles** | Visa, université, logement et vie quotidienne, pour votre arrivée. |
| **Bibliothèque** | Un texte tiré au hasard, niveau surprise, de débutant à avancé. |
| **Dictée** | Écoutez ou lisez une phrase russe et écrivez ce que vous entendez. |
| **Traduction** | Phrases FR ↔ RU, à votre rythme, auto-évaluées. |

Également inclus : un compteur de progression en XP, un mode sombre, une barre de recherche et l'installation comme application.
